
# BAER Shoes – Corporate Website

A premium, modern, responsive corporate website for **BAER Shoes**, designed to showcase the company's footwear manufacturing capabilities, products, technology, quality standards, and brand identity.

The project is built with clean and lightweight web technologies, making it easy to maintain, customize, and deploy.

## 🚀 Project Overview

The BAER Shoes website is a **B2B footwear manufacturing website**, not an e-commerce platform.

It focuses on:

- Company profile and brand story
- Footwear manufacturing expertise
- Product showcase
- Manufacturing process
- Quality and certifications
- Technology and innovation
- Sustainability
- Clients and partners
- Corporate events
- Contact and business enquiries

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic markup
- **CSS3** – Responsive layout, animations, and visual styling
- **JavaScript** – Interactive components and dynamic behaviour
- **Google Fonts / Web Fonts** – Modern typography
- **SVG / Web Images** – Branding and visual assets

## ✨ Key Features

### 🏢 Corporate Presentation
Professional company introduction with a premium industrial footwear aesthetic.

### 👞 Product Showcase
Dedicated presentation of footwear collections and manufacturing capabilities.

### ⚙️ Manufacturing Journey
Showcases the production workflow from raw materials to finished footwear, including:

**Cutting → Pre-Closing → Closing → Tube/UDP → Full Shoe → Lasting → Finishing → Inspection**

### 🧪 Quality & Compliance
Highlights quality-control practices, certifications, testing, and manufacturing standards.

### 💡 Technology & Innovation
Presents modern manufacturing technologies, production capabilities, and continuous improvement.

### 🌱 Sustainability
Dedicated section for sustainable manufacturing, responsible materials, waste reduction, and environmental initiatives.

### 🤝 Partners & Clients
Corporate presentation of business partners and client relationships.

### 📱 Responsive Design
Optimized for:

- Desktop
- Laptop
- Tablet
- Mobile

## 💻 Local Development

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Open the project:

```bash
cd BAER-Shoes-Reference
```

Then open `index.html` in your browser.

For the best development experience, use **Visual Studio Code** with the **Live Server** extension.
